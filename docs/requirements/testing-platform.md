# 测试业务

- PRJ-001：组织内项目、成员和固定项目角色管理；项目不可跨组织访问。
- AST-001：API测试与场景提供项目内目录及名称搜索；接口用例按接口聚合，历史用例目录保留；不建设标签体系。
- API-001：首版仅 HTTP，接口定义和用例使用独立模型，在API测试入口内整合展示；支持 query、headers、JSON、文本、URL 编码表单。
- NAV-001：左侧统一“API测试”入口；接口目录树同时展示接口，点击接口跳转到该接口详情。
- NAV-002：接口Header通过“API调试 / 接口用例”切换；接口用例页只展示该接口下的用例，创建时默认关联当前接口。
- NAV-003：接口、用例、场景及其他业务资源详情使用页面路由，组织/项目范围保留在URL，支持刷新与浏览器前进后退。执行参数、目录维护、成员授权和分享等操作性对话框保留。
- NAV-004：兼容历史用例；未关联接口或关联接口已不存在时，保留“未关联接口用例”入口，并支持重新关联，不因导航改造清表。
- API-002：支持无认证、Basic、Bearer、API Key；Cookie 仅在同次测试项运行内保持；OAuth、文件和二进制请求后续支持。
- CASE-001：用例关联接口，维护输入覆盖、变量、表单断言、变量提取、前后置 JS。
- SCN-001：顺序场景既可引用用例，也可创建独立请求；支持步骤输入覆盖、变量传递，默认失败停止，可按步骤继续。
- ENV-001：项目独立环境；脚本对环境的修改只在当前运行有效，不持久化写回；不同测试项隔离运行变量。
- DOC-001：接口定义生成文档；选定接口创建随机分享链接，可选密码、有效期，支持撤销，文档跟随最新定义。
- MOCK-001：平台统一提供匿名 HTTP Mock，独立 Mock 域名，方法、路径和请求字段条件匹配，返回固定状态码、headers、body，可配置延迟。

首版不提供测试文件上传、定时触发、外部机器任务触发、流程画布、分支循环、场景内并行、动态 Mock 或报告导出。
