# 共享平台

- IAM-001：平台管理员统一创建账号、组织和组织管理员，不开放注册、邮件邀请及找回密码。
- IAM-002：账号密码登录、退出、修改密码、管理员重置和禁用账号；账号可加入多个组织。
- IAM-003：全局账号、组织和组织角色共享；项目和项目权限由接入应用管理。
- IAM-004：平台管理员默认没有租户业务访问权；组织管理员管理本组织全部项目，并创建项目。
- IAM-005：项目管理员管理成员、Runner 和业务资源；编辑者维护资源及执行；只读成员仅查看脱敏结果，不能执行、改动或查看密钥。
- GW-001：统一域名按路径接入门户和测试应用，共享 HttpOnly Cookie 登录会话，Redis 保存会话，写请求校验 CSRF。
- GW-002：网关使用 Go 标准库，配置管理路由；公开登录、文档分享和匿名 Mock 由对应服务继续校验其边界。
- SEC-001：各服务独立数据库，租户业务表强制组织和项目范围；不能使用调用方提交的归属字段替换授权范围。
- SEC-002：重置密码、改密、禁用和退出撤销相应会话；密码不可明文保存，环境密钥加密存储，日志及报告脱敏。
